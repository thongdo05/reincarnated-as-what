Privacy

Reincarnated as WHAT?! does not create an account. There is no login, and there is no account to delete.

Leaderboard

If you post a score, the game sends these fields to a Supabase database (scripts/leaderboard.gd):

  • the leaderboard name you type
  • a random id the game creates and stores on the device, so that device keeps its row. It is not the advertising identifier
  • the score, how long the run lasted, which form it was, and whether that run defeated the dragon

The game does not send your email, phone number, contacts, photos, precise location, or health data. It does not sell this data.

Saved on the device

Best scores, the daily-run index, the leaderboard name and device id, and the sound on/off setting are stored on the device. The iOS, Android, and GitHub Pages builds keep those in the game's local save files.

The CrazyGames build stores those same items through the CrazyGames SDK Data module after the SDK starts, including a one-time copy from an older local save on that browser if one is already there. CrazyGames syncs that module for logged-in players. The game also loads the CrazyGames SDK, which reports gameplay events to CrazyGames. This page does not describe what CrazyGames itself collects.

Ads on the phone builds

The iOS and Android builds use Google AdMob: a banner on the death card, an interstitial between some runs, and an optional rewarded ad to choose the next form. Google receives the advertising identifier and related device data. On iOS the game shows Apple's tracking prompt. If you choose Ask App Not to Track, iOS does not give AdMob the advertising identifier. The web build and the CrazyGames build do not load AdMob.

Buying Remove Ads is handled by Apple or Google Play. The game keeps a local flag that ads are removed. It does not send the receipt or the payment to our server.
